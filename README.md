# 함수 탐구실 — 교과서 기반 상호작용 디지털 학습지

첨부 파일 **「[학생용] 1. 함수 · 01 함수의 뜻과 그래프 _ 교과서 순서.pdf」**를 재구성한, 설치가 필요 없는 정적 웹앱입니다.

## 포함 내용

- **개념 학습 6단계:** 대응 → 함수의 정의 → 정의역·공역·치역 → 서로 같은 함수 → 그래프 판별 → 함수의 종류
- **한 화면에 한 문제:** 교과서 111쪽·113쪽의 7개 원문 문제를 16개 문제 화면으로 분할
- **문제별 유형 및 전략 제시:** 대응 판별, 이차식 치역, 유리식 분모 제한, 같은 함수의 연립, 세로선/가로선 판별, 항등/상수 분류, 종합 분류
- **탐구 상호작용:** 대응 화살표, 그래프의 세로선·가로선 이동, 개념 퀴즈, 선택형 풀이
- **개별화 피드백:** 세 단계 힌트, 재도전, 정답 확인 시에만 해설 제공
- **수학 기록:** 관찰 메모, 수정한 생각, 태블릿·애플펜슬 필기 캔버스, 결과 JSON·CSV 출력
- **기기 대응:** iPad, 데스크톱, 모바일 반응형 / 서버 없이 `localStorage` 저장

## Antigravity에서 실행

1. 이 압축파일을 풀고 `function-explorer-app` 폴더를 **Antigravity**에서 열어 주세요.
2. `index.html` 파일의 **Preview / Live Server** 기능으로 실행합니다. 정적 파일이라서 빌드, API 키, 데이터베이스 설정이 필요 없습니다.
3. 로컬 미리보기가 없다면 `index.html`을 Chrome/Safari에서 직접 열 수도 있습니다. 이 경우 대부분의 기능은 오프라인으로 동작합니다.
4. 수정은 `styles.css`(디자인), `app.js`(개념·문항·채점), `index.html`(문서 기본 구조)에서 진행합니다.
5. 배포할 때는 3개 파일을 같은 위치에 업로드합니다. GitHub Pages·Netlify에 정적 사이트로 게시할 수 있습니다.

## 사용 전 교사용 확인 사항

- 문제는 **교과서 문제를 소문항 단위**로 나눴습니다. 원문 질문과 식/그림을 가능한 한 유지하되 설명, 보기, 조작 활동은 웹앱용으로 새로 구성했습니다.
- 함수의 종류(교과서 113쪽)를 탐구할 때는 **정의역과 공역을 모두 실수 전체**라고 명시했습니다. 수업의 맥락에 맞게 변경이 필요하면 `QUESTIONS`의 q10~q16 문항을 조정하세요.
- SVG 그래프는 교과서 그림을 복사한 이미지가 아니라 **수학적 관계를 디지털 방식으로 다시 그린 것**입니다. 원문 111쪽의 직선·포물선·원에 대해서는 동일한 유형을 보여 주는 예시 그래프를 사용합니다.
- 현재 채점은 정해진 선택지·수치에 대한 **규칙 기반**입니다. 손글씨를 AI가 해석·채점하거나, 교사가 실시간으로 조회하는 기능은 없습니다.
- 학생 기록은 **현재 브라우저에만 저장**됩니다. 캐시/사이트 데이터가 지워지면 기록이 소실될 수 있으므로 JSON 또는 CSV 파일을 내려받도록 안내하세요.
- 최초 사용 시 앱의 문항·정답을 교사가 검토하고 시험용 점수로는 사용하지 않는 것을 권장합니다.

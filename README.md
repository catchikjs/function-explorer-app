# Good쌤 — 8차시 함수 퀘스트와 디지털 탐구실

## 8차시 함수 퀘스트

고1 공통수학2의 함수와 그래프를 생활 맥락에서 탐구합니다. 기존 교과서 학습지·필기·퀴즈·12개 아케이드는 유지하며, 학생 홈과 교사 대시보드에 8차시 학습 경로를 연결했습니다.

1. **함수라는 약속** — 자판기와 함수의 조건, 예와 반례
2. **출발과 도착의 지도** — 정의역·공역·치역, 서로 같은 함수와 그래프
3. **되돌릴 수 있는 관계** — 일대일함수·일대일대응·항등·상수
4. **함수를 잇는 레시피** — 할인 순서, 합성함수와 정의 조건
5. **출력에서 입력으로** — 역함수의 존재 조건, 연산의 역순과 대칭
6. **가까워져도 닿지 않는 선** — 유리함수의 정의역·치역·점근선
7. **그래프가 시작되는 곳** — 무리함수의 조건·시작점·계수의 부호
8. **세상을 읽는 함수 디자이너** — 축제 비용·할인·역함수를 연결한 모델링

차시당 약 50분의 **개념 7분 → 조작 탐구 12분 → 확인 8분 → 개념 게임 5분 → 형성평가 8분 → 성찰 10분**을 권장합니다. 심화 문제와 추가 복습은 수업 뒤에도 이어갑니다. 모든 차시를 자유롭게 탐색할 수 있습니다.

- 예측, 두 가지 이상의 설정 비교, 관찰, 단계별 힌트, 선택한 답과 정오 이력을 저장합니다.
- 차시마다 확인 3문항, 형성평가 3문항, 심화 2문항, 복습 2문항, 개념 연결 게임을 제공합니다. 재평가에서는 수치·상황이 바뀌며 핵심 개념 질문은 반복합니다.
- 첫 평가와 모든 재평가를 따로 보관합니다. 최근 평가 2/3 이상과 탐구·성찰 기록을 남기면 차시 완료를 표시합니다. 이는 학습 경로의 표시이며 공식 성취수준 판정이 아닙니다.
- 서술·자신감은 자동 채점하지 않습니다. 교사가 설명의 근거와 생활 속 연결을 확인합니다.
- 완료 뒤 1·3·7일 간격의 기억 꺼내기를 추천하고, 이후에는 14일 간격을 사용합니다.
- 교사 대시보드의 **8차시 학습 과정**에서 차시별 평가, 첫 답→수정 과정, 예측·관찰·성찰과 심화 풀이를 조회하고 개인 피드백을 남깁니다.
- 학생은 홈에서 **나의 전체 기록 저장**, 교사는 대시보드에서 **학생 전체 기록 가져오기**를 사용합니다. 이 JSON에는 8차시뿐 아니라 기존 학습지·필기·퀴즈·게임 상태와 개인의 수다노트·질문·제출·피드백도 포함됩니다. 원본 업로드 파일은 별도로 내려받습니다.
- 동일 학생의 동일하거나 오래된 파일은 중복 반영하지 않습니다. 다른 학생의 기록은 현재 프로필에 덮어쓰지 않습니다. 새 기기에서는 빈 프로필에서 자기 기록을 이어서 가져올 수 있습니다.
- 교사가 내보낸 **개인 피드백 JSON**은 해당 학생 홈의 ‘피드백 파일 받기’에서 읽습니다. 로컬 파일 전달 방식은 발신자 인증을 제공하지 않습니다.

교육과정 범위는 [경기도교육청 공통수학1·2 성취평가 참고 자료](https://www.goe.go.kr/resource/goe/na/bbs_2675/2025/11/1914f44c-2310-4557-a93b-3543adfb7bb8.pdf)의 [10공수2-03-01~05]를 참고했으며, 학습 설명과 문제는 앱용으로 구성했습니다.

## 원본 학습자료와 오늘의 수업

**교사 대시보드 → 수업 학습자료**에서 제목·연결 차시·파일을 선택합니다. 파일당 20MB, PDF는 최대 80쪽의 자동 구성을 지원합니다. 원본 Blob은 IndexedDB에 그대로 보관하며 **원본 내려받기**로 복원할 수 있습니다.

**오늘의 수업**에는 `도입 → 업로드 원문 → 보충 개념 → 조작 탐구 → 마무리 질문 → 성찰` 발표 초안이 자동 생성됩니다. PDF.js로 PDF의 모든 지원 페이지를 읽고 원본 페이지를 전자칠판에 표시합니다. TXT·MD는 원문을 나누어 표시합니다. 원문 출처와 선택 차시의 보충 설명을 각 장에서 구분합니다. 슬라이드 제목·본문·교사 메모를 수정·저장할 수 있고, 좌우 키 이동·전체 화면·HTML 저장을 제공합니다.

이는 **규칙 기반 발표 초안 생성**입니다. NotebookLM/생성형 AI 요약, OCR, PPTX 변환은 연결되어 있지 않습니다. 이미지형 PDF는 원본 페이지로 표시하고, HWP·DOCX 등 자동 분석을 지원하지 않는 파일은 원본 보관 및 선택 차시의 보충 활동으로 구성합니다. 분석 실패도 표시하며 업로드할 때 교사가 보충 설명을 입력할 수 있습니다. HTML 저장본에는 텍스트와 출처만 포함되므로 원본 PDF·이미지는 별도 전달해야 합니다.

## 학교 서버 연결 (선택)

**기본값은 기기 저장 모드**입니다. 로그인 서버나 학교 계정은 아직 연결되어 있지 않습니다. 사이트 데이터를 지우면 로컬 기록과 업로드 파일이 소실되므로 JSON과 원본 파일을 따로 보관하세요. 프로필 전환과 교사 미리보기는 인증이 아닙니다.

연결을 위한 클라이언트는 `src/classroom-cloud.js`, 데이터베이스·권한 스키마는 `supabase/schema.sql`, 공개 환경 변수 예시는 `.env.example`에 있습니다.

1. 새 Supabase 프로젝트의 SQL Editor에서 `supabase/schema.sql`을 적용합니다. 기존 테이블이 있는 프로젝트에서는 관리자가 충돌 여부를 먼저 확인해야 합니다.
2. Authentication에서 학생·교사 계정을 만들고 `class_members`에 해당 Auth UUID, 학급 ID, 학급명, 표시 이름, 역할을 등록합니다. 같은 반은 동일한 `class_id`를 사용합니다. 브라우저에서 회원가입·역할 변경·학급 등록은 허용하지 않습니다.
3. `.env.local` 또는 Netlify 환경 변수에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`를 설정합니다. **공개 anon/publishable 키만 사용**하고 service_role/secret 키는 프런트엔드에 넣지 않습니다.
4. 다시 빌드하고 **저장·학교 계정 연결**에서 로그인합니다. 계정별 별도 프로필을 사용하며, 서버 기록과 이 기기 기록을 확인한 뒤 이어갈 기록을 선택합니다.
5. 자동 저장은 변경 후 1.5초에 실행됩니다. 서버 버전이 달라지면 덮어쓰기를 중지하고 충돌을 알립니다. 학급 기록·받은 메시지는 30초 간격으로 확인하며 수동 새로고침도 제공합니다.
6. 실제 운영 전 학교의 테스트 계정 두 개와 교사 계정으로 RLS 접근 범위, 저장 충돌, 메시지 전달을 검증합니다. 현재 작업에서는 서버가 없어 실서버 연동은 검증하지 않았습니다.

학생은 자기 기록만 쓰고 읽으며, 교사는 같은 학급 기록을 읽고 개인 메시지를 보냅니다. 역할은 서버에서 등록한 값을 사용합니다. 원본 학습자료·발표 파일은 서버 모드에서도 현재 기기 보관이며 파일 공유는 별도 전달합니다. 기존 질문 게시판의 답글·학습지 배포·집중 모드는 기기 기반 기능입니다.

검증: `npm test`, `npm run build`. 새 평가·기록·복습 로직 테스트와 기존 회귀 테스트를 포함합니다. Vanilla JavaScript/Vite, 루트 `index.html`, 기본 `dist` 출력을 유지합니다.

## 기존 교과서 기반 디지털 학습지

첨부 파일 **「[학생용] 1. 함수 · 01 함수의 뜻과 그래프 _ 교과서 순서.pdf」**를 재구성한, Vanilla JavaScript와 Vite를 사용하는 정적 웹앱입니다.

## 포함 내용

- **개념 학습 6단계:** 대응 → 함수의 정의 → 정의역·공역·치역 → 서로 같은 함수 → 그래프 판별 → 함수의 종류
- **한 화면에 한 문제:** 교과서 111쪽·113쪽의 7개 원문 문제를 16개 문제 화면으로 분할
- **문제별 유형 및 전략 제시:** 대응 판별, 이차식 치역, 유리식 분모 제한, 같은 함수의 연립, 세로선/가로선 판별, 항등/상수 분류, 종합 분류
- **탐구 상호작용:** 대응 화살표, 그래프의 세로선·가로선 이동, 개념 퀴즈, 선택형 풀이
- **개별화 피드백:** 세 단계 힌트, 재도전, 정답 확인 시에만 해설 제공
- **수학 기록:** 관찰 메모, 수정한 생각, 태블릿·애플펜슬 필기 캔버스, 결과 JSON·CSV 출력
- **기기 대응:** iPad, 데스크톱, 모바일 반응형 / 서버 없이 `localStorage` 저장

## 개발 및 빌드

추가 학습지는 **디지털 학습지** 메뉴에서 단원별로 선택합니다. 함수에는 합성함수와 역함수, 유리함수, 무리함수가 포함되며 원본 PDF도 열 수 있습니다. 무리함수는 39쪽 원본을 바탕으로 개념 도입·무리식 계산·정의역·역함수·그래프·평행이동 등을 56개 탐구 활동으로 구성했습니다. 각 활동에서 직접 조작하고 답을 확인하며, 단계별 힌트와 풀이·수식·펜 필기를 사용할 수 있습니다. 학습 기록과 마지막으로 본 문항은 학생별로 이 브라우저에 저장됩니다.

무리함수의 **루트 그래프 레일**에서는 함수식을 직접 입력하고 계수를 조절해 구슬의 길을 만듭니다. **무리함수 정의역 미로**에서는 근호 안의 부호와 분모의 조건을 판단해 열쇠를 모으고 탈출합니다. 두 게임은 각각 3단계이며 학습지와 개념 퀴즈의 게임 목록에서 실행할 수 있습니다. 기존 무리함수 답안 ID와 필기는 유지됩니다.

12개 아케이드 게임에는 각 분위기에 맞춘 배경음악과 발사·획득·카드·성공·실패 효과음이 있습니다. 게임 위의 소리 설정에서 음악과 효과음을 각각 끄고 전체 음량을 조절할 수 있으며 설정은 이 브라우저에 저장됩니다. 소리는 플레이 시작 후 재생되고, 일시정지·화면 이동·탭 전환 시 멈춥니다. 음악은 Web Audio API로 직접 합성해 외부 음원 요청 없이 재생합니다.

개념 퀴즈는 먼저 **주제 제목을 선택**하면 문제가 열립니다. **기초 발견 → 개념 적용 → 개념 연결 → 추론 도전 → 마스터 종합**의 5단계이며, 단계마다 6문항(10문항 이내)을 해결해야 다음 단계가 열립니다. 뒤 단계에는 매개변수·구간 제한·합성 및 역함수의 복합 조건이 추가됩니다. 5단계 완료 시 팡파레, 축하 효과와 마스터 인증서가 표시됩니다. 완료 단계와 인증은 학생별로 저장합니다. 기존 개념 퀴즈의 완료 기록은 1단계로 이어집니다.

주제를 다시 열면 수치·조건과 보기가 바뀌며, **다음 랜덤 문항**은 아직 해결하지 않은 주제 중에서 무작위로 출제합니다. 직전 문제는 연속해서 뽑지 않으며, 선택·채점·힌트·일시정지 중에는 현재 문제가 유지됩니다. 12개 게임도 새로 열거나 처음부터 시작할 때 식·정의역·카드·목표 좌표·집합 영역을 새로 구성합니다.

퀴즈의 **풀이 시간**은 제목을 눌러 문제를 열 때 시작하고 제출하면 멈추는 경과 시간 타이머입니다. 오답 후 다시 생각하면 시간을 이어서 측정하고, 다른 화면·탭·프로필 창을 보는 시간은 제외합니다. 실제 풀이 시간은 교사용 기록에도 저장됩니다. 정답과 오답에는 서로 다른 효과음이 나오며 퀴즈 화면에서 켜고 끌 수 있습니다. 문제·보기·해설의 루트, 분수, 지수, 역함수 표기는 KaTeX로 조판합니다.

학급 랭킹은 실제 학습 기록의 LP 합계로 계산하며 같은 점수는 공동 순위입니다. 퀴즈는 단계 최초 완료 시 `단계×100 LP`, 마스터 완료 시 추가 `300 LP`를 받습니다. 게임은 한 판의 단계 점수 합계가 기본 모드 `300 LP`, 도전 모드 `360 LP`이며, 미로·그래프·탄도·영역은 3단계, 슈팅은 6웨이브, 카드는 6쌍, 버블은 제거량의 1/3마다 반영합니다. 동일 세션의 동일 단계는 중복 가산하지 않습니다.

**교사 대시보드 → 게임·퀴즈 분석**에서 참여 상태, 진행 단계, 오류·힌트·성공 기록, 강점과 지원 신호, 최근 문제와 학생 선택을 확인합니다. 게임 진행 중에는 15초마다 상태를 저장하고, 최근 90초 이내의 진행 기록만 ‘플레이 중’으로 표시합니다. 오류나 힌트 신호는 교사 관찰을 위한 참고이며 서술 사고의 자동 평가가 아닙니다.

현재 랭킹과 분석은 **이 브라우저에 등록되거나 가져온 학급 기록 기준**입니다. 다른 기기의 학생은 **학습 기록 저장**으로 MATH PLAY LAB JSON을 저장하고, 교사는 **학생 기록 가져오기**로 모을 수 있습니다. 같은 학생의 오래된 파일이나 같은 파일을 다시 가져와도 최신 기록과 점수가 중복되지 않습니다. 기기 간 실시간 순위 공유, 교사 인증 및 중앙 저장에는 별도 서버 연동이 필요합니다.

원본 PDF와 표시용 페이지 이미지는 `public/worksheets/`에, 페이지 정보는 `src/workbook-data.js`에 있습니다. 기존 사용자에게도 새 학습지가 목록에 추가됩니다. 교사 미리보기에서 배포할 단원을 선택할 수 있으며, 추가 학습지의 기록도 JSON·CSV 내보내기에 포함됩니다.

```sh
npm install
npm run dev
npm run build
npm run preview
```

개발 서버 주소는 `npm run dev` 실행 결과에서 확인합니다. 빌드 결과는 `dist/`에 생성되며, `npm run preview`로 확인할 수 있습니다.

## 사용 전 교사용 확인 사항

- 문제는 **교과서 문제를 소문항 단위**로 나눴습니다. 원문 질문과 식/그림을 가능한 한 유지하되 설명, 보기, 조작 활동은 웹앱용으로 새로 구성했습니다.
- 함수의 종류(교과서 113쪽)를 탐구할 때는 **정의역과 공역을 모두 실수 전체**라고 명시했습니다. 수업의 맥락에 맞게 변경이 필요하면 `QUESTIONS`의 q10~q16 문항을 조정하세요.
- SVG 그래프는 교과서 그림을 복사한 이미지가 아니라 **수학적 관계를 디지털 방식으로 다시 그린 것**입니다. 원문 111쪽의 직선·포물선·원에 대해서는 동일한 유형을 보여 주는 예시 그래프를 사용합니다.
- 현재 채점은 정해진 선택지·수치에 대한 **규칙 기반**입니다. 손글씨를 AI가 해석·채점하거나, 교사가 실시간으로 조회하는 기능은 없습니다.
- 학생 기록은 **현재 브라우저에만 저장**됩니다. 캐시/사이트 데이터가 지워지면 기록이 소실될 수 있으므로 JSON 또는 CSV 파일을 내려받도록 안내하세요.
- 최초 사용 시 앱의 문항·정답을 교사가 검토하고 시험용 점수로는 사용하지 않는 것을 권장합니다.
